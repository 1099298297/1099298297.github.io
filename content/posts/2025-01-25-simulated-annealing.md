##### 一、模拟退火算法原理

模拟退火算法是一种基于概率的启发式搜索算法，**可以有效的避免局部最优解**。该算法模拟了金属的退火过程：把金属加热到高温，再缓慢冷却，以此来找最优解。

##### 如何、以及为何模拟金属退火过程？

物理退火过程分为三个阶段：

1. 加热：材料被加热到高温状态，原子处于高度活跃状态，能量较高
2. 冷却：材料冷却，原子逐渐稳定，能量降低
3. 平衡：温度足够低的时候，材料到达能量最低的稳定状态

**启发：**

* 试想如果让我们用肉眼算出一个迷宫的走法，我们会一步步计算概率，还是随机选取一个方向走走看？
* 试想如果走走看之后，发现无法抵达，我们是选择从头开始选取路线，还是回到上一步之前的某个随机位置重新走一遍？

<u>在求解时，我们可以像肉眼走迷宫一样随机多次地选择初始路线，然后慢慢基于当前路线随机改动。</u>

在这个过程中最重要的一点是**肉眼走迷宫时其实并非完全的随机改动路线**，而是我们结合了迷宫大小、当前路线等等因素，在脑内生成的一个**感官上较为合理的路线**（~~我不可能直接选一个看起来走不通的路~~）。

模拟退火算法正是解决了怎么"选取"一个**较为合理**的解。这里的合理并非指距离迷宫终点最近，而是有可能在最短路上——哪怕它看起来距离迷宫终点更远了。

**求解阶段：**

1. 初始阶段：**算法随机选择一个初始解**（可以是完全的随机）
2. 扰动阶段：**对初始解添加一个随机扰动，生成一个新解**，如果新解更优就接受新解，如果新解更劣，就<u>条件接受劣解</u>

扰动阶段又分两段：高温阶段**较高概率接受劣解**，以便更广阔地探索；低温阶段已经探索过了，此时**较低的概率接受劣解**，以便收敛到当前路线的最优解。

注意算法需要多次运行，也就是多次退火，因为要多次选取初始解。

**那么条件接受劣解是什么条件呢？**

```math
P(接受新解)=e^{-\Delta E/T}
```

其中 `ΔE = f(新解) − f(旧解)` 是新解与当前解的目标函数值之差，`T` 是当前温度。

当新解更优时 `ΔE<0`，`P>1`，则 100% 接受新解；当新解更劣时 `ΔE>0`，`P<1`，就以 `P` 条件接受新解。温度一直降低，所以接受劣解的概率也随之降低。

#### 二、用模拟退火解决最大子段和

首先设置退火操作次数 `fire`、初始温度 `T`、终止温度 `eps`、降温系数 `A`。

```cpp
const double T = 2e4, A = 0.98, eps = 1e-5;
const int fire = 15000;
```

退火过程伪代码：

```cpp
// 多次退火
for (int i = 1; i <= fire; i++) {
    // 生成初始解
    double t = T;          // 中间温度
    while (t > eps) {      // 温度还没降到最低
        // 添加随机扰动，生成新解
        // 计算新解与旧解目标函数的差值 delta
        if (delta <= 0)
            ; // 更优，直接接受
        else
            ; // 更劣，以概率 e^{-delta/t} 接受
        t = T * A;         // 降温
    }
}
```

下面说这道题怎么生成新解、怎么设计目标函数、怎么按概率接受新解。

题意下有四种子段操作：

1. 左移子段左端点
2. 右移子段左端点
3. 左移子段右端点
4. 右移子段右端点

所以：随机选取一个操作，再随机选取移动的距离 `dis`。`dis` 的范围最好和 `T` 成正比，这样温度下降时搜索范围也减小，便于收敛到最优值。然后判断新子段是否合法，合法才继续；再判断是否接受（`delta = 新子段和 − 旧子段和`）。为了快速计算子段和，需要用前缀和优化。
